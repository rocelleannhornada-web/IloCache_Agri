# **App Name**: AgriPrice Watch

## Core Features:

- Home Screen Dashboard: Dashboard providing an overview with a welcome message and quick access buttons.
- Price List: Display current prices of common crops filtered by location and updated with date and time.
- Price Alert Generation: Use generative AI tool to monitor trends in crop prices, generating a notification based on location and pre-set price thresholds.
- Price Trend Viewer: Simple chart or arrow indicator to show if prices are rising or dropping with historical data (7 days or 1 month).
- Location-Based Prices: Users select region to display local crop prices.
- Settings: User configurable preferences like region.

## Style Guidelines:

- Primary color: A desaturated yellow-green (#A3B86C) to evoke fields and growth, providing a calming and agricultural feel.
- Background color: Very light desaturated yellow-green (#F2F4EF) to provide a gentle, muted backdrop.
- Accent color: A brighter green (#728C00) to highlight key information and interactive elements, creating contrast against the background.
- Body and headline font: 'PT Sans' (sans-serif) for a modern and readable interface.
- Use clear, representative icons for crops and locations, with a style that is easily understandable at a glance.
- Prioritize clarity and ease of use in the layout, ensuring key information is immediately visible and accessible on the dashboard.
- Use subtle transitions and animations to indicate data updates and price trends.
